# Lunar Client Offline

An offline Lunar Client mod for **Minecraft 1.21.X**.

## Features

* Offline account support
* Lightweight
* Easy to use
* Client-side only

## Supported Versions

* 1.21.1
* 1.21.2
* 1.21.3
* 1.21.4
* 1.21.5
* 1.21.6
* 1.21.7
* 1.21.8
* 1.21.9
* 1.21.10
* 1.21.11

## Installation

1. Install Fabric Loader for your Minecraft version.
2. Place the `.jar` file into your **mods** folder.
3. Launch Minecraft using the Fabric profile.

## Requirements

* Fabric Loader
* Fabric API (if required)
